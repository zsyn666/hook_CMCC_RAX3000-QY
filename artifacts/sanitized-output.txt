## 稍后复查（自动回滚）

$ mdlcfg -g SYS_USER_LOGIN_LEVEL
3

$ dd if=/etc/tzcfg/system_config.use bs=1 skip=63040 count=1
3

$ dd if=/etc/tzcfg/system_config.bak bs=1 skip=63040 count=1
3

结论：修改曾短暂生效，但随后被守护进程/服务自动回滚；最终仍为 3，Web 登录等级未改变。

## 最终成功路径

### 1. 证明等级按账号分支返回

superadmin -> user_level=1
senior     -> user_level=2
admin      -> user_level=3

### 2. 只改 superadmin 名字（仍失败）

mdlcfg -a SYS_SUPER_LOGIN_NAME=admin
mdlcfg -a SYS_SUPER_LOGIN_PWD=<admin 密码>
mdlcfg -c

登录 admin -> user_level=3
INIT_PAGE -> userName1=admin, account_level=3

原因：登录逻辑先匹配 SYS_USER_LOGIN_NAME。

### 3. 把普通用户分支改名（成功）

mdlcfg -a SYS_USER_LOGIN_NAME=admin_legacy
mdlcfg -c

登录 admin：

{
  "success": true,
  "cmd": 100,
  "user_level": "1",
  "AUTH": "AUTH",
  "sessionId": "[REDACTED]"
}

INIT_PAGE：

{
  "success": true,
  "cmd": 80,
  "account_level": "1",
  "login_times": "3",
  "userName1": "admin",
  "userName2": "senior",
  "userName3": "admin_legacy",
  "web_page_hide": "4fc1f0033f0fff1ffffff"
}

### 4. SYS_USER_LOGIN_LEVEL 是“最近一次登录等级”

before:                          1
login senior: user_level=2  ->   SYS_USER_LOGIN_LEVEL 变为 2
login admin:  user_level=1  ->   SYS_USER_LOGIN_LEVEL 变回 1
